Capacidades del Sistema

Diseñado para Análisis Financiero Cuantitativo

Arquitectura modular que combina ingeniería de variables bursátiles con potentes modelos supervisados.

📊

Ingesta Multi-Fuente

Integración directa con la API Alpha Vantage con mecanismo automático de respaldo (Fallback) sintético para asegurar disponibilidad continua del 100%.

📈

Indicadores Técnicos

Cálculo dinámico de RSI (Relative Strength Index), Bandas de Bollinger, MACD, medias móviles simples/exponenciales y volatilidad rolling.

🤖

Machine Learning Supervisado

Entrenamiento interactivo de algoritmos de regresión y clasificación (Random Forest, Gradient Boosting, Ridge Regression, Decision Trees).

🔮

Proyección de Escenarios

Generación de pronósticos iterativos hacia el futuro acompañados de escenarios de riesgo (Optimista, Base y Pesimista).

📐

Evaluación Cuantitativa

Diagnóstico riguroso mediante métricas $R^2$, RMSE, MAE, Exactitud, Matriz de Confusión e Importancia de variables clave.

⚡

Integración Continua (CI/CD)

Automatización mediante GitHub Actions para validar sintaxis, dependencias y mantener la integridad del código en cada subida.

Metodología Industrial

Ciclo de Vida CRISP-ML(Q)

Estructurado bajo los estándares internacionales de calidad en proyectos de Machine Learning.

1
Negocio & Datos
Definición de objetivos predictivos financieros e ingesta bursátil.
2
Ingeniería Datos
Construcción de Lags, medias móviles, volatilidad, RSI y MACD.
3
Modelado
Ajuste de hiperparámetros y entrenamiento supervisado de algoritmos.
4
Evaluación
Validación cruzada, cálculo de errores y matriz de confusión.
5
Despliegue
Dashboard interactivo en Streamlit y Landing Page representativa.
6
Monitoreo
Auditoría continua y actualización de series temporales.
